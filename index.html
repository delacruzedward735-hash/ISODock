Designed for Linux

Simple where it should be.
Powerful where it matters.

IsoDock keeps the workflow familiar and direct while adding Linux-native packaging, diagnostics, safer runtime handling and a distinct boot experience.

USB

Install & update

Create or update a multiboot USB from the native desktop interface without introducing another application stack.

✓

Runtime verification

Built-in checks validate boot payload integrity, dependencies, branding and the packaged engine before you rely on the drive.

UI

IsoDock boot theme

A silver-and-blue GRUB interface with a dynamic ISO list, blue selection state and real Ventoy hotkeys underneath.

Quick start

Install on Debian-based Linux.

The current production candidate targets amd64 systems such as Ubuntu, Zorin OS, Linux Mint and Debian.

01 · DOWNLOAD

Get the .deb release

isodock_1.0.0-6_amd64.deb
02 · INSTALL

Install with APT

sudo apt install ./isodock_1.0.0-6_amd64.deb
03 · VERIFY

Run diagnostics

isodock --doctor

Transparent about what IsoDock is.

IsoDock is an independent downstream project powered by the Ventoy open-source engine. The project preserves upstream attribution and distributes downstream changes under GPL-3.0-or-later.

IsoDock is not affiliated with or endorsed by the official Ventoy project. Boot and disk-engine components retain their respective upstream licenses and notices.
