# Support

## Bugs and feature requests

Use GitHub Issues for reproducible IsoDock bugs and focused feature requests.

Before filing a bug, run:

```bash
isodock --doctor
```

Include the IsoDock version, Linux distribution/version, desktop environment, CPU architecture, whether the issue occurs during GUI launch / USB install / USB update / boot, and a redacted diagnostic log where useful.

## Safety

Do not attach full disk images containing private data. Never test a reported write-path bug on a disk containing important files.

## Upstream Ventoy behavior

If the issue reproduces unchanged in official Ventoy 1.1.17, note that in the issue. IsoDock may track the issue downstream while preferring a fix that can be contributed upstream where appropriate.
